# DevSecOps – Security Reports

This folder contains the daily automated security review reports generated by the **Daily Security Review** GitHub Actions workflow.

## Report structure

Each report is a Markdown file named `security-report-YYYY-MM-DD.md` and includes the following sections:

| Section | Description |
|---|---|
| Executive Summary | High-level overview of findings and risk level |
| Dependency Audit | Results of `npm audit` (vulnerabilities in dependencies) |
| Static Code Analysis | Results of ESLint with security-focused rules |
| Known Vulnerable Libraries | Results of Retire.js scan |
| Recommendations | Suggested remediation steps |

## Schedule

The workflow is triggered automatically every day at **21:00 (America/Bogota, UTC-5)** and can also be run manually from the GitHub Actions tab.

## Manual run

Go to **Actions → Daily Security Review → Run workflow**.
