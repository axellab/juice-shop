API Endpoints:
==============

GET  /rest/data-processing/health
     └─> Returns service health status

GET  /rest/data-processing/operations
     └─> Returns list of available operations

POST /rest/data-processing/process
     └─> Transforms data based on operation
         Body: {operation, data, options}

POST /rest/data-processing/process-multiple
     └─> Processes data from multiple sources
         Body: {sources: [{name, data}, ...]}


Data Flow Example:
==================

1. Client Request:
   POST /rest/data-processing/process
   {
     "operation": "aggregate",
     "data": [
       {"category": "A", "value": 10},
       {"category": "A", "value": 20}
     ],
     "options": {
       "groupBy": "category",
       "sumFields": ["value"]
     }
   }

2. Route Handler (routes/dataProcessing.ts):
   - Validates request format
   - Calls core service

3. Core Service (lib/dataProcessing.ts):
   - Validates operation
   - Applies security checks (isSafeKey)
   - Executes aggregateData()
   - Returns result

4. Response:
   {
     "status": "success",
     "result": [
       {"category": "A", "value": 30}
     ]
   }

Integration Points:
===================

The microservice can be integrated with:

1. Frontend Applications
   └─> JavaScript/TypeScript fetch() calls

2. Other Backend Services
   └─> HTTP REST API calls

3. Scheduled Jobs
   └─> Cron jobs or task schedulers

4. Data Pipelines
   └─> ETL processes

5. External Services
   └─> Webhooks or API integrations
